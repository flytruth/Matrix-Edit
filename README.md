**MatrixEdit - Video Editor for Linux**


A CapCut-like professional video editor for Linux (with future Windows port planned)
Project Status: ⏸️ Paused
This project is currently on hold. Developing a full-featured video editor alone proved to be more complex than anticipated. The build system, Qt6 integration, FFmpeg handling, and timeline logic presented significant challenges for a solo developer.
What Was Built
✅ Core Architecture

Qt6-based modern UI with dark theme
Multi-panel layout (Media Bin, Preview, Timeline, Properties)
OpenGL-accelerated video preview
FFmpeg-powered media handling
✅ Features Implemented

Project creation with aspect ratio selection
Media bin with thumbnail view
Timeline widget with clip management
Playback controller with play/pause/seek
Basic undo/redo system
Technologies

Framework: Qt6 (Widgets, OpenGL, Multimedia)
Language: C++20
Media: FFmpeg 62.x
Build: CMake
Platform: Linux (CachyOS/Arch) with Windows port planned
Why It's Hard
Building a professional video editor requires:

Complex timeline and track management
Real-time video processing and rendering
GPU acceleration for smooth playback
Cross-platform compatibility
Memory management for large media files
Doing this alone while maintaining quality is extremely challenging.
The Fun Part
Despite the difficulties, this was an incredibly fun and educational project! I learned:

Advanced Qt6 development
FFmpeg integration
Real-time video processing
CMake build system
OpenGL rendering
